# CryptoKeno - Cross-Platform Gaming App

A real-time Crypto Keno gaming application with Android and iOS support.

## Features
- 🎮 Real-time Keno gameplay
- 💰 Cryptocurrency integration
- 📊 Live leaderboards
- 🔔 Real-time notifications
- 👥 Multiplayer support
- 📱 Native iOS & Android
- 🎨 Beautiful UI/UX

## Project Structure
```
cryptokeno-app/
├── android/          # Android app (Kotlin/Jetpack Compose)
├── ios/              # iOS app (Swift/SwiftUI)
├── backend/          # Node.js/Firebase backend
├── shared/           # Shared models and utilities
└── docs/             # Documentation
```

## Quick Start

### Android
```bash
cd android
./gradlew assembleDebug
```

### iOS
```bash
cd ios
pod install
xed CryptoKeno.xcworkspace
```

### Backend
```bash
cd backend
npm install
npm run dev
```

## Requirements
- Android: API 26+
- iOS: 14.0+
- Node.js 16+
